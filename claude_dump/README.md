# .ai

Instructions for AI agents working on this repository.

| File | Purpose |
|---|---|
| `rules.md` | Binding rules for implementation work. Read first. |

Tool-specific config files (`.cursorrules`, `CLAUDE.md`, `AGENTS.md`)
should be thin pointers to `rules.md`, not copies. One source of truth —
a rule that exists in two places will diverge.

Project documentation lives at the repository root:

| File | Purpose |
|---|---|
| `architecture.md` | Design decisions and the numbered decision log |
| `implementation.md` | Build order, critical path, league facts |
| `followups.md` | Open verifications, with deadlines and consequences |
| `council-prompts.md` | Persona system prompts and the brief schema |
